# บ้านคิด · ชุดฝึกคณิตศาสตร์ 1.0

เว็บแอปภาษาไทยสำหรับฝึกคณิตศาสตร์ ป.4–5 บนแท็บเล็ต ชุดฝึก 1.0 มี 12 หมวด หมวดละ 3 ระดับ และโจทย์สร้างจากแม่แบบตามระดับชั้น รุ่นนี้ขยายเนื้อหาและกระดาน ไม่ใช่การรับรองว่าครอบคลุมหลักสูตรทุกตัวชี้วัดหรือเปิด AI ให้ใช้ข้อมูลเด็กจริงได้แล้ว โหมด AI ยังคงเป็นผู้ใหญ่ทดลองตามการตั้งค่าเดิม

สำหรับ GitHub Pages ดู [GITHUB_HOSTING.md](GITHUB_HOSTING.md) ใช้ `npm run build:pages` สร้าง `docs/` รุ่นสาธิตที่ไม่มี backend

## ใช้งานได้ในโหมดสาธิต

โจทย์หลายขั้น: ในเมนูฝึกเศษส่วน เลือก “บวกหลายขั้น”, “ลบหลายขั้น” หรือ “บวก–ลบสลับ” ได้ ข้อละ 4–5 จำนวน ใช้ตัวส่วนหลากหลาย ระดับเริ่มต้นใช้ 4 จำนวนกับส่วนขนาดเล็ก ระดับฝึกคล่องใช้ 4–5 จำนวน และระดับท้าทายใช้ 5 จำนวน ส่วนโหมดคละ ป.5 ระดับท้าทายจะสุ่มหลายขั้นร่วมด้วย ตรวจคำตอบแบบเศษส่วนอย่างต่ำหรือเศษส่วนสมมูลได้ และรักษาผลลัพธ์ระหว่างทางไม่ให้ติดลบ หมวดบวก/ลบจำนวนเต็มระดับ 2–3 เพิ่มเป็น 3–5 จำนวนด้วย

เศษส่วน: เลือกทักษะย่อยจากเมนู “ฝึกเศษส่วน” ได้ ได้แก่ บวก/ลบส่วนไม่เท่ากัน บวก/ลบส่วนเท่ากัน คูณ หาร หลายขั้น และจำนวนคละ โหมดคละของ ป.5 ระดับ 1–2 เน้นบวกและลบส่วนไม่เท่ากันตั้งแต่เริ่ม ระดับ 3 เพิ่มคูณ หาร หลายขั้น และจำนวนคละ ตัวส่วนมีคู่ที่ไม่เป็นเท่าของกัน เช่น 3 กับ 4 และ 6 กับ 8 คำใบ้แนะนำตัวส่วนร่วมและการคูณทั้งเศษและส่วน ตรวจเฉลยจากโจทย์และทักษะเดียวกันทั้งฝั่งเว็บและ backend ไม่ได้อ้างว่าครอบคลุมบทเศษส่วนทั้งหมด เช่น โจทย์ปัญหาเศษส่วนหลายขั้นยังขยายต่อได้ อ้างอิงเนื้อหา ป.5: [Project 14 สสวท. การบวก การลบเศษส่วนที่ตัวส่วนไม่เท่ากัน](https://proj14.ipst.ac.th/p5/p5-math-book1/math-p5b1-008/)

จำนวนคละ: มีเมนูบวก ลบ คูณ หารโดยเฉพาะ แสดงจำนวนเต็มข้างเศษส่วนแบบบน/ล่าง พร้อมคำใบ้แปลงเป็นเศษเกิน การทำส่วนร่วม หรือการคูณด้วยส่วนกลับเมื่อหาร เฉลยแสดงทั้งเศษเกินอย่างต่ำและจำนวนคละเมื่อเหมาะสม คำตอบพิมพ์แบบ `2 1/3` หรือ `7/3` ได้ทั้งคู่ รูปแบบโจทย์สอดคล้องกับหัวข้อ [การบวก การลบจำนวนคละ](https://proj14.ipst.ac.th/p5/p5-math-book1/math-p5b1-009/) และ [การหารจำนวนคละ](https://proj14.ipst.ac.th/p5/p5-math-book1/math-p5b1-021/) ของ สสวท.

- โจทย์จากแม่แบบที่ตรวจเฉลยได้: บวก ลบ คูณ หารลงตัว คำนวณระคน เศษส่วน ทศนิยม การวัดและหน่วย พื้นที่/รูปทรง เวลา อ่านข้อมูล และโจทย์ปัญหา แยก ป.4/ป.5 และความยาก 3 ระดับ รองรับโจทย์หลายขั้น เศษส่วนลบ/คูณ และปริมาตรในระดับที่กำหนด ลดการซ้ำของโจทย์ในแท็บปัจจุบันด้วยรายการชื่อโจทย์ 200 ข้อล่าสุด
- กระดาน 1200×1400 (เดิม 1200×680) เพิ่มหน้าได้สูงสุด 12 หน้า/ข้อ ปุ่มขยายพื้นที่เขียน โหมดเลื่อนกระดาษ หัวปากกาเริ่มต้นเล็กลง ปรับขนาดได้บนแท็บเล็ต ยางลบ ย้อนกลับ และล้างเฉพาะหน้า ทุกหน้าอยู่ในหน่วยความจำของแท็บ รีเฟรช ปิดหน้า หรือเปลี่ยนโจทย์จะล้างลายมือ ไม่เก็บภาพ/เสียงเพิ่มใน localStorage
- AI ได้ภาพเฉพาะหน้าที่เปิดอยู่ พร้อมหมายเลขหน้า โดยครอบเฉพาะบริเวณที่มีหมึกและเว้นขอบเพื่อลดการย่อจนอ่านไม่ชัด การสลับหน้าจะยกเลิกคำตอบที่ใช้ภาพเก่า
- ตรวจคำตอบที่พิมพ์ด้วยตัวคำนวณ รองรับเลขไทย เศษส่วนสมมูล และจำนวนคละ
- คำใบ้ ภาพแถบเศษส่วน ภาพรูปสี่เหลี่ยม/ทรงสี่เหลี่ยมมุมฉาก และแผนภูมิแท่ง เสียงอ่านของอุปกรณ์หากมีเสียงไทย
- ประวัติผลการฝึกใน localStorage ไม่บันทึกภาพหรือเสียง เพิ่มความยากเมื่อทำถูกโดยไม่ใช้คำใบ้ 3 ข้อติด

โหมดสาธิตไม่อ่านลายมือและไม่สนทนา AI จริง คำตอบในช่องแชตสาธิตคือคำใบ้สำเร็จรูป ไม่ใช่การวิเคราะห์คำถาม

## เปิด API สำหรับผู้ใหญ่ทดลอง

ห้ามส่ง API key ในแชตหรือใส่ใน client code สำหรับ Sites ให้ใช้ OpenAI Developers plugin / skill `openai-platform-api-key` เพื่อสร้างและตั้ง secret ตามขั้นตอนที่รองรับ หาก plugin ยังไม่มีให้เชื่อมก่อน

สำหรับรันในเครื่อง: สำเนา `.env.example` เป็น `.env` แล้วตั้งค่าเฉพาะในเครื่องของคุณ:

```dotenv
OPENAI_API_KEY=your-key
AI_ADULT_TEST_ENABLED=true
OPENAI_VISION_MODEL=gpt-4.1-mini
OPENAI_REALTIME_MODEL=gpt-realtime-2.1
```

สำหรับ Cloudflare Workers ตั้งชื่อตัวแปรเดียวกันที่ Runtime variables and secrets โดย OPENAI_API_KEY ต้องเป็น Secret เปิด Cloudflare Access แบบ All traffic ก่อน backend รุ่นนี้ตรวจสิทธิ์จาก `ctx.access.getIdentity()` ไม่ใช้ Sites identity headers หลัง deploy เปิด `/api/config` ตรวจ hasKey และ accessReady ก่อนเปิด AI_ADULT_TEST_ENABLED=true จากนั้นเปิดตั้งค่าผู้ปกครองในหน้าเว็บและยืนยันว่าใช้ข้อมูลผู้ใหญ่/ข้อมูลจำลอง (การยืนยันนี้อยู่เฉพาะแท็บ ไม่เก็บข้ามการเปิดหน้า)

- `/api/review`: ส่งภาพกระดานไป Responses API แบบ structured output, `store:false` ให้ AI อ่านและให้คำใบ้ แล้วเซิร์ฟเวอร์ตรวจคำตอบกับโจทย์ที่สร้างใหม่จาก seed ไม่เชื่อ answer ที่ client ส่ง ผลอ่านคำตอบต้องให้ผู้ใช้ยืนยันก่อนบันทึกคะแนน
- ตรวจอัตโนมัติ: รอหยุดเขียน 1.8 วินาที เว้นอย่างน้อย 7 วินาทีระหว่างการส่ง จำกัด 50 ครั้งต่อการเปิดหน้า ยกเลิก/ทิ้งผลที่กระดานเปลี่ยน
- `/api/voice`: แลก SDP ฝั่งเซิร์ฟเวอร์กับ Realtime API ผ่าน WebRTC ไม่ส่ง API key ให้ browser เปิดเสียงจากการกดปุ่มเท่านั้น ส่งภาพล่าสุดเมื่อผู้ใช้พูดจบ แล้วจึงขอเสียงตอบกลับ ปิดสายเมื่อซ่อนหน้า/ครบ 10 นาที
- เสียงสนทนาเป็นคำแนะนำ ไม่ให้คะแนน คะแนนใช้ตัวตรวจและการยืนยันของผู้ใช้
- โหมดเสียงมีตัวเลือกไมค์ แถบวัดเสียง ปุ่มทดสอบลำโพง ปุ่มเล่นเสียงเมื่อเบราว์เซอร์บล็อก และสถานะการเชื่อมต่อ ไม่บันทึกเสียงหรือ token ลงในสถานะนี้ รอ session.created ก่อนทักทาย และรอ input_audio_buffer.committed ก่อนขอคำตอบจากเสียง
- การฟังไทย: โหมดคุณภาพใช้ `gpt-realtime-2.1` เป็นค่าเริ่มต้น (เปลี่ยนได้ด้วย OPENAI_REALTIME_MODEL) และโหมดประหยัดใช้ `gpt-realtime-2.1-mini` ใช้ semantic_vad แบบ eagerness=high เพื่อจับจบประโยคเร็วขึ้น (อาจตัดช่วงหยุดคิดของผู้พูดเร็วขึ้น) มี noise reduction แบบ far_field สำหรับแท็บเล็ต / near_field สำหรับหูฟัง และข้อความถอดเสียงด้วย `gpt-realtime-whisper` language=th ค่าถอดเสียงคิดเพิ่ม ข้อความถอดเสียงเป็นผลจากโมเดลอีกชุด ไม่ใช่หลักฐานว่าระบบสนทนาได้ยินตรงกันทุกคำ โมเดลสนทนารับเสียงโดยตรง
- ครูเสียงเรียกเครื่องมือ `math_coach` ผ่าน `/api/tutor` เมื่อต้องวิเคราะห์วิธีทำหรือผู้เรียนยังไม่เข้าใจ ใช้ Responses API `gpt-6.1-sol` reasoning=low (เปลี่ยนด้วย OPENAI_TUTOR_MODEL) พร้อมโจทย์ที่สร้างใหม่ฝั่งเซิร์ฟเวอร์และภาพกระดานถ้ามี ไม่ส่ง secret ให้เบราว์เซอร์ ไม่ให้คะแนนด้วยเสียง เรียกเฉพาะเมื่อโมเดลเลือกใช้ จึงไม่ใช่ทุกคำตอบมาจาก GPT-6.1 และไม่รับประกันเทียบเท่า ChatGPT ทั้งผลิตภัณฑ์ คิดเครดิต API เพิ่มและอาจช้ากว่าบทสนทนาทั่วไป หากบัญชียังใช้โมเดลนี้ไม่ได้จะแจ้งข้อผิดพลาดโดยไม่แอบเปลี่ยนรุ่น
- ใช้ภาพกระดานเดิมในสายเสียงเมื่อ revision ไม่เปลี่ยน และยกเลิกคำปรึกษาที่ล้าสมัยเมื่อพูดแทรก/เขียน/เปลี่ยนโจทย์ สถานะเสียงบันทึกเวลาจาก speech_stopped ถึง audio_buffer.started เท่านั้น ไม่รวมช่วงตรวจจบประโยคหรือการเล่นเสียงจริงที่ลำโพง จึงไม่ใช่การวัดความหน่วงทั้งหมดที่ผู้ใช้รู้สึก ยังไม่มีผลวัดความเร็วบนเครือข่ายและแท็บเล็ตจริง
- โหมดคุณภาพมีราคาต่อ audio token ที่ไม่ใช่ cache ประมาณ 3.2 เท่าของ Mini ตามราคาที่ตรวจ 2026-11-16 (ยังไม่รวมข้อความ ภาพ ประวัติ และค่าถอดเสียง) เลือกโหมดได้ในตั้งค่าผู้ปกครอง และต้องจบสาย/เปิดใหม่เมื่อเปลี่ยนโหมด
- จัดการ API ล้มเหลว ไม่มีเครดิต ไม่อนุญาตไมค์ ไม่มีเสียงเครื่อง ภาพอ่านไม่ชัด และผลตอบช้า

## ขอบเขต beta

- เผยแพร่แบบ owner-private สำหรับเจ้าของทดลองเท่านั้น ยังไม่ใช่ระบบบัญชีเด็กหรือโรงเรียน
- ยังไม่เปิดใช้งานกับข้อมูลส่วนบุคคลเด็ก: ต้องจัดการความยินยอม เงื่อนไขการใช้บริการ การเก็บ/ลบข้อมูล และ Zero Data Retention ก่อน `store:false` ไม่เท่ากับ ZDR
- เนื้อหาเป็นตัวอย่างระดับชั้น ยังไม่ได้ตรวจเทียบหลักสูตรไทยครบทุกตัวชี้วัด
- การอ่านลายมือและเสียงไทยต้องประเมินกับอุปกรณ์จริง ไม่รับประกันความแม่นยำหรือ latency
- การสร้างโจทย์ใช้แม่แบบที่กำหนดขอบเขตและสุ่มตัวเลข ยังไม่สร้างโจทย์อิสระด้วย AI
- localStorage เป็นข้อมูลแยกตาม browser/origin ไม่ใช่ฐานข้อมูลข้ามเครื่อง
- Rate limit ใน Worker memory ช่วยลดการกดซ้ำ แต่ไม่ใช่ distributed quota หรือ spending cap ต้องตั้งงบ/ติดตามที่ API project ด้วย
- ห้ามเปลี่ยน Sites เป็น public ก่อนเพิ่มสิทธิ์ใช้งานและโควตาฝั่งเซิร์ฟเวอร์ที่เหมาะสม
